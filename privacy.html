Loopling Privacy Policy

Last updated: 28 September 2026

Loopling is an automated publishing tool operated by Ezra Behr for his own channels, YouTube @Loopling_Official and Instagram @loopling_official. It is not offered to the public and has no other users.

What data Loopling accesses

With the channel owner's authorization, Loopling uses the YouTube API Services to:

  • upload videos that Loopling generates to the owner's own YouTube channel, and
  • read the performance statistics (views, watch time, likes, shares) of those videos.

It uses the Instagram API in the same way for the owner's own Instagram account. Loopling does not access any other user's data, and it does not collect data from viewers.

How the data is used and stored

Video statistics are stored in a private database on a device controlled by the owner and are used only to decide which kinds of videos to make next. Authorization tokens are stored in private files on that device and are never shared. No data is sold, shared with third parties, or used for advertising.

Google and YouTube terms

Loopling uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Loopling's use of information received from Google APIs adheres to the Google API Services User Data Policy.

Revoking access

The channel owner can revoke Loopling's access at any time from Google security settings. Stored statistics are deleted on request.
